Review or recover an alert

Use the local command on the authoritative database. Reading the report sends nothing:

uv run python -m home_finder.pipeline.delivery_admin --database data/properties.db

Stop the runner before reconciling. Add --delivery KEY using the exact delivery reference and --evidence-ref REF with a short, non-secret explanation reference. Choose one action:

  • --message-ids ID,ID: acknowledge the uncertain current part using every message ID actually observed in the configured chat.
  • --retry-confirmed-undelivered: retry after verifying non-delivery or correcting a definite rejection. Earlier acknowledged parts stay saved.
  • --suppress: stop the remaining alert without claiming it was delivered.

An unknown response is not proof of non-delivery. Automatic retries for uncertain parts remain disabled. Planned media must be restored byte for byte; changing the payload requires a separate reviewed revision.
