# CROSS — cross-cutting audit of src/home_finder (122 modules, 32,271 lines)

Method (all scripts in `scratchpad/cross/`):
- `astdup.py` — AST-normalised (docstrings stripped, locals/args renamed) hash of every function body → exact duplicates.
- `astnear.py` — structural hash (all names/attrs/constants erased) → near-duplicates.
- `names.py`, `strs.py` — same function name / same string literal (≥10 chars) defined in ≥2/≥3 modules.
- pylint `duplicate-code` at 8 and 5 lines (`pylint_dup8.txt`, `pylint_dup5.txt`; pylint installed into .venv only).
- `comments.py` + `narr.py` — per-module comment/docstring density and narration-pattern scan (`density.txt`, `narr_all.txt`).
- `lazy.py` — classifies every in-function import in src (stdlib / third-party / internal, and whether hoisting it would create an import cycle); measured import times and `sys.modules` side effects.
- `wrappers.py`, `docargs.py`, `doclen.py` — one-line wrappers with no src caller; docstrings naming absent params (none found); docstrings longer than bodies.

Headline: exact copy-paste between modules is rare (4 small groups). The real cross-module cost is (a) the same *policy* implemented several times with drift (HTTP transport, floor-area plausibility, challenge detection, image media types), (b) plumbing left behind after a feature was switched off (early-stop, cost defaults), (c) import-structure residue (lazy imports, re-exports, one upward db→web import), and (d) a small amount of planning/ticket narration.
