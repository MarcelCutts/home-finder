## Reviewed changes in test boundaries

- Badge evidence rules run directly against production reconciliation. Three full analyzer cases retain the listing-correction and saved-receipt wiring. The second model’s repeated badge grid was removed; provider/model pairing has its own suite.
- The old acoustic helper reproduced production logic. Current tests inspect actual evaluation requests for supported construction, unknown construction, absent evidence and legacy unstructured evidence.
- Cross-run lifecycle cases retain the real storage and delivery planner. Source membership, price history, cache copying and gallery disagreement have dedicated suites.
- Source-area cases retain exact/bound/range semantics, plausibility limits, persistence, matching, scoring and presentation in the responsible modules.
- Search, criteria and matching cases combine repeated positive/negative examples. Property-based matching still tests symmetry, grouping membership and signal bounds.
- Location categorization was a helper defined in a live diagnostic test file. Its tests are retired, not counted as production coverage. Production location selection remains in test_filters/test_location.py.
- Seven live-marked Rightmove mapping cases move out of the live lane: the existing offline location-mapping suite owns those constants. Live tests now assert observed enrichment and close clients.
- Web cases now assert selected options, resulting home IDs/order, stored history and guard responses. The traversal regression reaches the actual guard rather than a router 404.

Coverage and successful execution are corroborating evidence, not completeness guarantees. An exhaustive old-assertion/parameter-to-new-assertion proof remains outside this declaration ledger; the current report makes no claim of total action coverage.
